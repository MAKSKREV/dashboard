# Дашборд завода: YouTube

Статус: работает. Каждые 3 часа GitHub Actions (`.github/workflows/collect.yml`) запускает `collect.mjs`. Скрипт берёт просмотры и лайки из открытых RSS YouTube (ключи не нужны, вход тоже) и дописывает снимок в `data/history.json`. Страница `index.html` (GitHub Pages) по этим снимкам рисует динамику и показывает, у каких каналов за последние сутки не было ролика.

- Каналы в `channels.json`. Новый канал: добавить строку с `id` (UC…), `name`, `group`.
- RSS отдаёт только 15 последних роликов канала. Если ролик выпал из RSS, в сумме канала остаются его последние известные просмотры.
- Подписчиков RSS не отдаёт.
- Кнопка «Обновить статистику» запускает `collect.yml` через GitHub API. Нужен fine-grained токен с Actions: Read and write на этот репозиторий, он хранится только в localStorage браузера.
- Снимок вручную: `node collect.mjs`
